Por que ele trava: o nome não é o som

Quase toda criança aprende primeiro o nome das letras: bê, ó, éle, á. Só que, para ler, ela precisa de outra coisa: perceber o som que cada pedacinho da palavra faz.

Nome das letras

bê · ó · éle · á

Juntando, sai "beoelea"

Som das sílabas

BO+LA

Juntando, sai BOLA

Os especialistas chamam isso de consciência fonológica: perceber que as palavras são feitas de pedacinhos de som. A boa notícia é que ela pode ser treinada, de um jeito leve, com brincadeira, um pouquinho por dia.

Quando a criança entende que BO + LA = BOLA, a leitura destrava. É exatamente esse passo que o aplicativo da Bené treina.
